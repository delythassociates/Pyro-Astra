### 2. Runtime AI Agent: Ask ASTRA
- **Hybrid Architecture**: Dual-mode scientific intelligence copilot operating in either OFFLINE mode (deterministic algorithmic engine) or LIVE mode (tool-use only LLM planner).
- **Supported Provider & Exact Model**: Groq (`qwen/qwen3.8-27b`) via official Groq OpenAI-compatible REST API. Tested live across the 130-probe evaluation suite: 38 real Groq API calls made (35 compliant, 3 rewritten by the verifier), 92 answered/refused pre-LLM offline. On the free tier, most queries run OFFLINE via the deterministic engine; live AI is strictly opt-in via UI toggle. Invocation uses deterministic parameters (`temperature: 0.0`, `response_format: { type: "json_object" }`).
- **Environment Key Only**: Configured strictly via server-side environment variables (`GROQ_API_KEY`). Secrets are never embedded in client bundles (`NEXT_PUBLIC_*`), never committed to source repositories, and never required for reproduction (`npm run reproduce` runs 100% offline).
- **Graceful Fallback & Circuit Breaker**: If no API key is detected, if network connectivity is interrupted, or if external API requests exceed the 12-second timeout or return HTTP 429/500/503 errors, Ask ASTRA automatically and seamlessly defaults to the offline deterministic engine with zero downtime or user-facing crashes.
- **Rate Limiting & Quotas**: Enforced with a 2,500ms minimum inter-request interval (safely below Groq free-tier 30 RPM and 8,000 TPM limit). Automatic backoff with jitter on retryable errors, maximum 5 concurrent in-flight requests per process, and hard 12,000ms query timeout.
- **Deterministic Verifier Interception**: 100% programmatic interception via `src/lib/validate.ts`. Every number, physical unit, combustible fuel, and investigation ID generated by the model is intercepted before rendering. Ungrounded assertions are vetoed ("Code has the final say").
- **Policy Enforcement**: Strict, deterministic refusal of partial-gravity predictions (SPEC Section 2 Rule 5), rocket/propellant queries (SPEC Section 2 Rule 6), safety guarantees, and ungrounded fabrications.
- **Operational Evidence**: Complete redacted request/response exchange traces, schema declarations, and verifier audit logs are fully documented in `docs/LIVE_MODE.md`, `data/live-audit-log.json`, and accessible on the `/trust` transparency page.

### 3. Investigation Digests
- **Generation**: AI-drafted from raw PSI investigation metadata and experiment summaries.
- **Review Status**: Labeled as **"AI-drafted from NASA metadata; not independently reviewed"** throughout the application.
- **Citations**: Every digest sentence carries direct citation chips to NASA PSI DOIs and source records.

### 4. Machine Learning & Synthetic Data Purge
- **Discarded Synthetic Data**: An earlier AI-generated synthetic raw dataset (`scripts/populate_raw_datasets.py`, `/raw`) was completely discarded and deleted.
- **Purged Ungrounded Extrapolations**: In accordance with the non-negotiable principle of zero data invention and strict physical grounding, all speculative ungrounded polynomial regression and arbitrary predictors were permanently removed. Surrogate modeling under PREREGISTERED Rev 5 is governed strictly by a 3-tier domain-gate refusal protocol.
- **Pure Empirical Evidence**: PYRO-ASTRA reports exclusively verified physical evidence from official NASA technical reports (`NASA/TM-20210011385`, `NASA/TP-2015-218570`) and authentic NASA PSI GEODE API metadata.
